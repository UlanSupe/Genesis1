# VIDEO_SCRIPT — демонстрационное видео TraceForge (≈ 4 минуты)

Формат: запись экрана (терминал + браузер) с голосом за кадром. Все числа ниже получены реальными запусками на текущем коммите;
перед записью прогоните команды ещё раз — цифры в демо детерминированы (seed 7), поэтому должны совпасть. Если что-то не совпало — говорите то, что видите на экране.

## Подготовка (за 5 минут до записи)

```powershell
cd C:\путь\к\Genesis1
pip install -e .
python -m traceforge demo --no-color --report-dir reports      # прогрев + создаёт reports/demo_report.html
```

* Терминал: шрифт крупный, ширина ≥ 110 символов, тёмная тема, `NO_COLOR` уже учитывается (`--no-color`).
* Браузер: открыть `reports/demo_report.html`, отдельной вкладкой — вкладку Actions репозитория (если CI зелёный, покажите его в финале).
* Закрыть всё лишнее (почту, мессенджеры). Не показывать ключи и личные данные.
* Не показывать `private/` как «взлом»: это открытые наборы, закрытая истина показывается только в блоке `--instructor`.

## Ответы на вероятные вопросы жюри (30 секунд на каждый)

* *«Не слишком ли просто, что baseline решает всё?»* — Да, ошибки выводимы из публичных данных по построению, это гарантирует независимый валидатор. Мы измеряем среду, а не модель; различимость награды показана ablation-исследованием.
* *«Как агент не может прочитать истину?»* — В его процессе её нет (генерация и оценка — в процессе оценщика); утечки ловит сканер на каждом сообщении; Python-агенты дополнительно запускаются под audit-hook песочницей; для враждебных — Docker-команда без сети и без монтирования данных (проверена на уровне команды).
* *«Можно ли подогнать под id или порядок строк?»* — Нет: пары-двойники меняют id, порядок, описания и смещения времени, а `verify_links` доказывает, что все финансовые связи сохранены.
